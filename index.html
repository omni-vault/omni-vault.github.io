Works with the managers you already use

OmniVault connects to each manager the way that manager allows: directly through its API, or through its official command-line tool on your computer. Several accounts of the same manager are fine.

  • BitwardenDirectly. bitwarden.com and bitwarden.eu; your vault is decrypted in the browser.Read and write
  • VaultwardenDirectly. Also self-hosted Bitwarden servers.Read and write
  • PassboltDirectly. Versions 4 and 5 with sharing; OpenPGP runs in the browser.Read and write
  • 1PasswordLocal helper and the official op CLI.Read and write
  • LastPassLocal helper and the official lpass CLI.Read and write
  • passLocal helper with pass and GnuPG.Read and write
  • Proton PassLocal helper and the official pass-cli, which Proton offers on paid plans only.Read and write
  • KeePassXCKeePassXC’s own browser integration via keepassxc-proxy, end-to-end encrypted.Read, write logins
  • Everything elseImport CSV, JSON or KeePass XML exports from other managers and browsers into any account above.Import

Everything in one list

Each account gets its own color, so you always see where an entry lives. Logins for the site you’re on come first.

Everyday use

  • Search by name, username, address, folder or account
  • Copy username, password and TOTP code with one click
  • Fill with a click, Ctrl+Shift+L or the context menu
  • Optional button inside login fields and a “Save login?” prompt
  • Create and edit logins, notes, cards, identities and folders
  • Password generator with strength meter and history

Passkeys

  • Create passkeys on websites and sign in with them
  • Stored in your Bitwarden or Vaultwarden account, in the format the official Bitwarden apps use
  • No matching passkey? Your browser’s own passkey handling takes over

Across managers

  • Copy, move or mirror entries between accounts and providers
  • Find duplicates within and across accounts
  • Spot reused and weak passwords, checked locally only
  • Import from other managers; export to Bitwarden JSON or CSV
  • Trash view for Bitwarden and Vaultwarden

Available in English, German, Spanish, French, Italian, Portuguese (Brazil), Simplified Chinese and Japanese. Popup, sidebar or its own window, as you prefer.

Your passwords stay between you and your manager

OmniVault has no servers of its own and sends no telemetry. It talks only to your password manager’s server or to its official tool on your computer.

No master passwords stored
Decrypted keys live only in the browser’s session memory and are discarded when you lock, after your chosen timeout, when your computer locks and when the browser closes.
Optional PIN unlock
A 4–12 digit PIN opens a sealed in-memory copy of your session. Five wrong attempts discard it; after a restart your master password is required again.
Filling only when you ask
Websites never receive entries on their own. OmniVault fills on a click and asks first if the address doesn’t match.
Site-bound passkeys
A website only gets its own passkey back. Private keys never reach the popup and leave the background only encrypted.
Established cryptography
WebCrypto, OpenPGP.js, argon2id and @noble/ciphers instead of home-grown crypto. No code from the official clients.
Minimal permissions
Access to self-hosted servers and native apps is requested only when you add such an account. Passbolt server keys are pinned on first sign-in.

Install

OmniVault isn’t in the Chrome Web Store or on addons.mozilla.org yet. Until then, build it from source and load it into your browser.

  1. Build

    You need Node.js and git.

    git clone https://github.com/omni-vault/OmniVault.git
cd OmniVault
npm install
npm run build   # creates dist/chrome and dist/firefox

  2. Load into your browser

    • Chrome, Edge, Brave: open chrome://extensions, turn on Developer mode, click Load unpacked and select dist/chrome.
    • Firefox 128 or later: open about:debugging#/runtime/this-firefox, click Load Temporary Add-on and select dist/firefox/manifest.json.

  3. Add your accounts

    Click the OmniVault icon, then the plus sign and Add account. Bitwarden, Vaultwarden and Passbolt sign in directly. For 1Password, LastPass, pass, Proton Pass and KeePassXC, register the local helper once:

    cd native
python3 install.py --chrome-id <EXTENSION-ID>
python3 install.py --chrome-id <EXTENSION-ID> --keepassxc   # with KeePassXC

    The helper needs Python 3.8 or later and nothing else. Details are in the README.
